# Sanremo Data Analysis – Looker Studio Report

## Descrizione
Questo progetto analizza i dati del Festival di Sanremo dal 1951 al 2023, con focus su partecipazioni e vittorie degli artisti.

## 🎯 Obiettivo
Comprendere:
- se la costanza premia
- quanto è difficile vincere
- la distribuzione delle partecipazioni

## 📈 Insight principali
- La maggior parte degli artisti partecipa una sola volta
- Solo pochi artisti vincono più di una volta
- La costanza non garantisce la vittoria
